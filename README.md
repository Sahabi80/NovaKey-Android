# NovaKey

**A Native Android Keyboard Built for Everyday Typing.**

NovaKey is an Android keyboard application designed to provide a customizable and responsive typing experience across the Android ecosystem.

Built using Android's native `InputMethodService`, NovaKey aims to work system-wide, allowing users to type in applications such as WhatsApp, Facebook, Messenger, Chrome, and more.

## ✨ Project Goals

- Build a native Android keyboard.
- Provide a responsive and smooth typing experience.
- Support system-wide keyboard input.
- Improve typing efficiency and customization.
- Explore AI-powered typing assistance.

## 🚀 Planned Features

- [ ] Complete symbol and punctuation support
- [ ] Smooth backspace and long-press deletion
- [ ] Adjustable keyboard height
- [ ] Bangla typing support (Avro-like experience)
- [ ] Neon Blue keyboard theme
- [ ] Custom visual effects and glow
- [ ] AI-powered typing assistance

*Feature availability may change as development progresses.*

## ⚙️ Getting Started

### Prerequisites

- Android Studio
- Android SDK
- JDK compatible with the project's Gradle configuration

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Sahabi80/NovaKey-Android.git
   ```

2. Open the project in Android Studio.

3. Allow Gradle to sync the project.

4. Build and run the application on an Android device or emulator.

### Enable NovaKey

After installing the application:

1. Open Android Settings.
2. Navigate to Languages & Input / Keyboard Settings.
3. Enable NovaKey.
4. Select NovaKey as your default keyboard.

*Menu names may vary depending on the Android version and device manufacturer.*
